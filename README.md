## Claude Persian · کلاد فارسی

[![Release](https://img.shields.io/github/v/release/229amini/ClaudeCodePersianPort?style=flat-square&label=release)](https://github.com/229amini/ClaudeCodePersianPort/releases/latest)
[![Stars](https://img.shields.io/github/stars/229amini/ClaudeCodePersianPort?style=flat-square)](https://github.com/229amini/ClaudeCodePersianPort/stargazers)
[![License](https://img.shields.io/github/license/229amini/ClaudeCodePersianPort?style=flat-square)](https://github.com/229amini/ClaudeCodePersianPort/blob/main/LICENSE)

Windows terminals can't lay out Persian. Mixed Persian and English lines come out in the wrong order, and you can't type a half-space. Claude Persian runs the real Claude Code CLI underneath and draws it in a right-to-left window, so your account, settings, skills and hooks stay as they are.

<a href="https://github.com/229amini/ClaudeCodePersianPort"><img src="https://raw.githubusercontent.com/229amini/ClaudeCodePersianPort/main/docs/screenshots/before-after.png" alt="Claude Code in the Windows terminal next to Claude Persian" width="760"></a>

- Persian interface, right to left, with permission prompts in Persian
- Several Claude accounts in one window; when one hits its usage cap, you carry on with the next
- Connect to a Linux server over SSH and work there from your own PC
- Conversations side by side, with full-text search across all of them
- Python standard library only, bound to localhost, MIT licensed
